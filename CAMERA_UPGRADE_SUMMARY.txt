QUICK START GUIDE
================================================================================

STEP 1: UPLOAD FIRMWARE
   a. Upload firmware/DrainGuard/DrainGuard.ino to ESP32 DevKit V1
   b. Upload firmware/ESP32-CAM/DrainGuard_Camera.ino to ESP32-CAM
   c. Power on both modules

STEP 2: TEST WIFI CONTROL
   Connect to WiFi: DrainGuard-Robot (password: DrainGuard123)
   
   # Test camera status
   curl http://192.168.4.1/api/camera/status
   
   # Capture photo
   curl -X POST http://192.168.4.1/api/camera/capture
   
   # Set quality
   curl -X POST "http://192.168.4.1/api/camera/quality?value=2"
   
   # View stream
   Open browser: http://192.168.4.50/stream

STEP 3: TEST BLUETOOTH CONTROL
   a. Use nRF Connect app on phone
   b. Scan and connect to DrainGuard-XXXX
   c. Find service 7b0d1001-5f6b-4c4f-9a7e-2f3b4d5e6f70
   d. Write to RX char: {"command":"camera","action":"capture","id":1}\n
   e. Read notifications from TX char

STEP 4: INTEGRATE WITH MOBILE APP
   See firmware/CAMERA_CONTROL_GUIDE.md for:
   - React Native examples
   - Python examples
   - Arduino/C++ examples

================================================================================
SUPPORT & TROUBLESHOOTING
================================================================================

COMMON ISSUES:

1. Camera not available
   → Check ESP32-CAM is powered and connected to hotspot
   → Verify IP 192.168.4.50 is reachable
   → Check ESP32-CAM serial output

2. BLE commands fail
   → Ensure JSON format is correct
   → Include newline \n at end of command
   → Check device is paired

3. Stream is laggy
   → Lower quality to 0 or 1
   → Move closer to hotspot
   → Check WiFi signal strength

4. Commands timeout
   → Verify IP addresses
   → Check free heap memory
   → Restart modules if needed

DEBUGGING:
- Serial monitor: 115200 baud
- Check /api/status for system health
- Monitor ESP32-CAM serial output
- Use nRF Connect for BLE debugging
